# v0.17.1 Release Notes

**[⬇ Download obsidian-vault-compiler-v0.17.1.zip](obsidian-vault-compiler-v0.17.1.zip)**

**Released:** 2026-10-31

## Bug fixes

### Each problem is reported once, where it was written (US-8.5, #88, #93)
Looking up a link no longer reports anything by itself; the step that uses
the link reports what it found, once, with the note and line.
- Maps no longer add a false "Missing include" to the compiler's internal
  warning list (#88).
- A missing embed, wiki link or image is listed once instead of two or three
  times; the warnings file was already right for these.
- **A name that matches several notes is now reported in the warnings file**:
  `Ambiguous filename dup.md; using a/dup.md`, once per link or embed, with
  its note and line. Before, the compiler chose one silently. In Obsidian the
  file is chosen by Obsidian's own link lookup, and the message names the
  one it chose. A name found next to the note is not ambiguous.

The compiled text is byte-identical to v0.17.0 for the fixture vault.

## Known issues
- #95: warnings raised while links are converted (missing wiki link,
  ambiguous link) give a wrong line number when the same note embeds another
  note above the link.
- #94: image embeds with a web address (`![logo](https://…)`) are removed
  from the output and reported as a missing asset.

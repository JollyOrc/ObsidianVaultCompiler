# v0.15.0 Release Notes

**[⬇ Download obsidian-vault-compiler-v0.15.0.zip](obsidian-vault-compiler-v0.15.0.zip)**

**Released:** 2026-10-27

## New features

### Tidy map labels (US-4.9, T-4.9-A)
A new setting, **"Tidy map labels"** (on by default), changes compiled maps:
- the hex numbers (`0402` …) are left out;
- each label sits in the middle of its hex instead of at the bottom;
- a label wider than its hex is broken into lines at spaces; a single word
  that is too wide is hyphenated (after an existing `-` or `&` where possible).
Lines may use 80 % of the hex width; line height is 1.2 × the font size.
Links in labels are kept. Maps inside Obsidian are not changed, and the Text
Mapper plugin is not modified or copied: the compiler changes the SVG the
plugin returns.

If a map was drawn differently than expected (another plugin version), it is
left as drawn and a notice says so. A word that cannot be fitted even when
hyphenated gives a notice per map.

## Changed behaviour
- Map PNG names now end in `t` when labels are tidied
  (`<hash>_<font key>t.png`), so tidied and untidied maps never mix in one
  output folder (US-4.9 AC-9).

## Breaking changes
- Compiled maps look different by default (no numbers, centred labels).
  Turn the setting off for the v0.14 look.

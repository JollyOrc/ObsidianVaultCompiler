## New features

### Details: a few facts of a note as data (US-9.5, #120, #121)
A new setting, **Detail marker keys** (empty by default: off), lists property
names. A note brought in whole that has at least one of them is a *detail
note*. Only the listed properties go into the document, in the setting's
order, as an `o2t-details` block directly under the note's heading, for the
typesetting plugin Obsidian2Typst (0.14.0 or later), which prints them as one
row of badges and shows the block that way in Obsidian. The note does not
become an entry.

With `Detail marker keys` = `pace, kind, needs, starter`:

````markdown
### Rope Laying
```o2t-details
pace: Swift
kind: craft
needs: "[[#Basket Knots|Basket Knots]]"
```
Three strands, twisted against each other, make a rope.
````

- Every other property (`tags` too, unless listed) is left out; names in
  lower case.
- Text, numbers and checkboxes are written as they are (`true` or `false`);
  an empty property is written empty.
- A list or a map is left out and reported (*Detail value is not text*); a
  note with nothing left gets no block.
- **Links stay links.** A link in a value becomes the same in-book link as in
  body text, written `[[#heading|text]]`, which the typesetter prints as a
  link. A link to a note that is not in the book becomes plain text, with the
  same warning as in body text.
- Only notes brought in whole get the block (not sections, quotes or the
  starting note). A note embedded twice gets a block each time.
- A note with both an entry marker key and a detail key is an entry: it gets
  only the entry block, and the warnings file says so (*Entry keys and detail
  keys in one note*). Two keys that differ only in case: the first is
  written, with a warning.
- A `dataviewjs` line holding `dv.view(...)` is removed without leaving a gap
  between the heading and the block (pinned by tests; no new rule).

The block's format is specified by its reader (Obsidian2Typst,
`docs/technical/details-block.md`).

## Changed behaviour
None. With **Detail marker keys** empty, the compiled text of every existing
book is byte-identical to 0.22.0.

# v0.10.1 Release Notes

**Download withdrawn (2026-10-30):** this build bundled the npm package
`text-mapper` (AGPL-3.0-or-later, CC-BY-SA-4.0), which the Unlicense of this
project cannot carry. Use v0.14.0 or later
([#89](https://github.com/JollyOrc/ObsidianVaultCompiler/issues/89)).

**Released:** 2026-10-27

No change to compiled output. This release fixes the build and release process
and brings the documentation in line with the code.

## Build gate (T-7.1-B, US-7.1)

- `npm run build` now runs typecheck → lint → tests → bundle → deploy → release
  and stops at the first failure. Before, it ran no lint and no tests, although
  SCAR-006 recorded that it did. Proven with a deliberately failing test: the
  build exited non-zero and `main.js`, the deployed copy and `releases/` stayed
  unchanged.
- New scripts: `typecheck`, `test:unit` (unit + fuzz, 114 tests),
  `test:integration` (integration + sanity, 246 tests); `npm test` runs both.
- `npm run lint` passes: Node globals are configured for `*.mjs`, and an unused
  import was removed from `release.mjs`.
- `deploy` also copies `styles.css`. `manifest.json` needs no copy:
  `plugin/manifest.json` is a symlink to the deployed manifest (SCAR-012).
- Added the missing `version-bump.mjs`; `npm version <x.y.z>` now updates
  `package.json`, `manifest.json` and `versions.json` together.

## Documentation

- Heading stories moved from Epic 7 to Epic 6: heading normalisation is now
  US-6.3; preamble heading injection (US-6.4) and pass-through embed (US-6.5) are
  written into `userstories.md` for the first time. Old IDs: US-7.1 (second use),
  US-7.2 and US-7.3 of the ticket backlog and of the v0.8.0 to v0.10.0 notes.
- Decisions of 2026-10-27 on heading behaviour recorded in US-6.1 and US-6.3 to
  US-6.5 (OD-1 to OD-6). They are **not implemented in this release**.
- Release notes live only in `releases/`; the duplicate `development/releases/`
  folder was removed and the checklists in `CLAUDE.md` and `AGENTS.md` updated.
- `docs/technical/dependencies.md` now records how TextMapper is really
  rendered (npm `text-mapper` 0.1.10, desktop only); the gap to US-4.2 to US-4.4
  is ticket T-4.2-GAP.

## Known issues

- KD-1: with "Normalise headings" on, links to normalised files can point to
  anchors that do not exist (`userstories.md`, Epic 6).
- With "Normalise headings" off, US-6.1 filename headings are not applied
  (OD-4; fix planned with the heading work).

# v0.10.0 Release Notes

**[⬇ Download obsidian-vault-compiler-v0.10.0.zip](obsidian-vault-compiler-v0.10.0.zip)**

## US-7.2 — Preamble Heading Injection (revised)

Reworked preamble title derivation: numeric prefixes are stripped and hyphens are preserved in injected titles. `2.2.2 Third-Level.md` → `### Third-Level` (not `Third Level`).

Fixes:
- `lastOriginalHeadingLevelInParent` formula corrected from hardcoded `1` fallback to `parentDepth + 1`.
- AC-10: heading tracker skips injected title when computing `lastOriginalHeadingLevel` for subsequent embeds.

## US-7.3 — Pass-Through Embed (revised)

Anchor pass-throughs now supported: `![[file.md#Section]]` as the sole content of a wrapper file extracts and shifts the named section to `ptTargetDepth`.

`isEffectivelyHeadingFirst` recursively follows pass-through chains to determine qualification.

## Build pipeline

`npm run release` now runs automatically after every production build:
- Creates `releases/<id>-v<version>.zip` (contains `main.js`, `manifest.json`, `styles.css`)
- Writes `releases/vX.Y.Z.md` with the release notes
- Rewrites `releases/RELEASES.md` listing the last 5 versions

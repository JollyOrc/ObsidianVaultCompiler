## Bug fixes

### Compiling from a note no longer changes your settings (US-7.2, US-7.3, #81, #104)
**Compile vault from this file** used to store the note you right-clicked as
the starting note — even if you then pressed Cancel — and stored the folder and
file name you typed (or picked with **Browse**) in the settings. The next
**Compile vault** from the command palette then started from that note. Now
everything you choose in the export window is used for that one compilation
only; the settings stay as they are.

**Migration:** if you relied on the export window to change your defaults, set
the starting note, folder and file name in the plugin settings instead.

### The export window
- The line *Resolved output path* changes as you type and after **Browse**;
  before, it showed the path from when the window opened.
- **Enter** in either field compiles, **Escape** cancels. Enter does not
  compile while an input method is still composing a character.

## Changed behaviour

### Settings are saved after you stop typing (US-7.1, #82, #104)
The text fields in the settings were saved on every key press. They are now
saved half a second after the last key press, and at once when you close the
settings window or switch the plugin off, so nothing you type is lost. Both
places that show the resolved output path change as you type.

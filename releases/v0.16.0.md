## New features

### Consistent empty lines in the compiled document (US-6.6, T-6.6-A)
The compiled document now always has:
- at most one empty line in a row;
- exactly one empty line before every heading;
- no empty line between a heading and what follows it — text, list, table,
  image or callout — except one before a following heading;
- no empty lines at the start, and one line break at the end.
Code blocks are left exactly as written.

In the example book this removed 211 double empty lines, 283 empty lines
after headings and added the missing empty line before 66 headings (with
"Normalise headings" on); no text was lost.

## Bug fixes

### Lists of `[text](path)` links are imported (US-1.3, T-1.3-B)
A list in which every item is a link to a note is a table of contents, and
each item is imported in place. Until now this only worked for `[[…]]` links:
`[text](path.md)` items stayed links, so in `index2compile.md` the chapters
`4 Glossary` and `5 Back notes` were missing from the book. Both syntaxes now
work alike, also in numbered and nested lists and with `[[Note|alias]]`.

### A list is judged as a whole
A list is a table of contents only when **every** item is a link (or embed) to
a note, as US-1.3 always said. A list with any plain text, a link with more
text around it, a website, a missing note or another file is left as written.
(Before, each line was judged on its own.) Embed lines lose their bullet in
any list, as before.

## Changed behaviour
- Notes that only want to point at other notes should write the links in a
  sentence or with text around them, not as a bare list of links — otherwise
  the notes are imported. (The glossary entries `Skilltree Branch` and
  `Reflex Skills` were rewritten this way.)

## Bug fixes

### `#` lines inside code blocks are no longer headings (KD-3, T-6.6-B)
Every step that looks for headings now skips code blocks (``` or ~~~):
- a section embed (`![[Note#Section]]`) no longer ends at a `# …` line inside
  a code block, which could leave the block unclosed;
- heading normalisation no longer shifts such lines (`# code` stayed
  `# code`, it no longer becomes `### code`);
- a `#` line in code no longer counts as the heading above an embed, nor as
  a note's first heading.
One shared helper decides what a heading and a code block are, for all steps.

The example book compiles byte-identical to v0.16.0.

## Known issues

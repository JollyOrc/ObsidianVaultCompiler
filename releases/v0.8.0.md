# v0.8.0 Release Notes — Preamble Heading Injection (US-7.2)

## What changed

When `normaliseHeadings` is enabled, files that do not start with a heading (*preamble files*) now receive a filename-derived title heading injected before their content, and all internal headings are shifted consistently below that title. Previously these files were embedded as-is.

## Injection rules

| File type | Injected title level |
|---|---|
| Prefix preamble (e.g. `2.2.2 Third-Level.md`) | Prefix depth (h3 for 3 segments) |
| No-prefix preamble | Last heading seen in the parent file above the embed point + 1; defaults to h1 if no prior heading |

## Canonical example

```
index.md:             ![[2.2.2 Third-Level.md]]
2.2.2 Third-Level.md: Some text\n# Heading\n![[Detailbit.md]]\nSome more text
Detailbit.md:         Some text inside\nSome more text inside\n# Heading inside Detail\nlast text
```

Output:

```markdown
### Third-Level
Some text
#### Heading
##### Detailbit
Some text inside
Some more text inside
###### Heading inside Detail
last text
Some more text
```

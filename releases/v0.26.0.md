# v0.26.0 Release Notes

**[⬇ Download obsidian-vault-compiler-v0.26.0.zip](obsidian-vault-compiler-v0.26.0.zip)**

**Released:** 2026-11-25

Encounter lists: a room note names its creatures, and the compiled book carries
their properties for the typesetter, which prints the room's encounter rows
already filled in.

## New features

### Encounter lists (US-9.6, #134, #135)
A callout of the type `encounter` in any compiled note:

```markdown
> [!encounter] Night watch
> - 2 × [[Fen Hare]] — nibbling reeds
> - 1d4 × [[Bog Wight|wights]]
> - 1 × Lost Pilgrim — no stats
```

becomes an `o2t-encounter` block in the compiled file: each line a row with the
creature's name, its count as written and its note, and, for a link to a note
with one of your **Entry marker keys**, that note's properties (images left
out). The creature's note is only read, not compiled. Links in the callout no
longer turn into "not embedded" warnings. Obsidian2Typst 0.17.0 prints the
block as prefilled encounter rows.

New setting **Encounter callout type** (section **Entry data**), default
`encounter`; empty switches it off. New warnings: `Encounter list: no rows`,
`Encounter list: … lines not read (lines …)`, `Encounter list: no note "…"`.

## Changed behaviour

None for notes without an encounter callout: every existing book compiles byte
for byte as before.

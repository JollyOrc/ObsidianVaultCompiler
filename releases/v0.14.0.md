# v0.14.0 Release Notes

**[⬇ Download obsidian-vault-compiler-v0.14.0.zip](obsidian-vault-compiler-v0.14.0.zip)**

**Released:** 2026-10-27

Maps are now drawn by the Text Mapper plugin installed in your vault, so
compiled maps look like the ones in Obsidian.

## Changed behaviour

### Maps come from the installed Text Mapper plugin (US-4.2, T-4.2-B)
- The compiler calls the plugin's own code-block processor for each map.
  Compared with v0.13.0 the PNGs now have:
  - a transparent background (the plugin's white background is removed);
  - black outlines around every hex;
  - labels as Obsidian shows them (`Ice Armour`, not `Ice Armour|Ice Armour`);
  - coordinates as `0402`.
- Maps also render on mobile; nothing is written to the system's temp folder.

### New setting: Map font (US-4.8)
- Empty (default): the font Obsidian uses for your notes, read when you
  compile. Otherwise any CSS font list, e.g. `Georgia, serif`.

## Breaking changes
- **Without the Text Mapper plugin installed and enabled, maps are not drawn**:
  each becomes a `TextMapper Render Failure` comment, and one notice per compile
  says why. There is no built-in fallback any more (US-4.3 withdrawn).
- `include` lines in maps are ignored, as the plugin does; the plugin always
  provides Gnomeyland and Apocalypse. No map in the example vault uses `include`.
- The npm package `text-mapper` (AGPL) and its four terrain files are no longer
  bundled.

## Manual check
M14 (2026-10-27): transparent background, black outlines, single labels,
`0402` coordinates and path outlines confirmed in Obsidian. Two findings —
Times with an empty "Map font", and a font change not reaching existing PNGs —
are fixed in v0.14.1.

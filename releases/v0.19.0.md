# v0.19.0 Release Notes

**[⬇ Download obsidian-vault-compiler-v0.19.0.zip](obsidian-vault-compiler-v0.19.0.zip)**

**Released:** 2026-11-01

## Breaking changes

### Jump links are written the way Obsidian finds them (US-2.3, #99)
The compiled document is read in Obsidian. Obsidian finds a heading by its
text, not by a GitHub-style slug, so until now every jump link to a heading of
more than one word led nowhere there. Links now point at the heading text:

| Link in your note | Before | Now |
| --- | --- | --- |
| `[[1.3 Grit & Zeal]]` | `[Grit & Zeal](#grit-zeal)` | `[Grit & Zeal](#Grit%20&%20Zeal)` |
| `[[1.2 Third-Level]]` | `[Third-Level](#third-level)` | `[Third-Level](#Third-Level)` |
| a note titled `Rules (optional)` | `#rules-optional` | `#Rules%20%28optional%29` |
| a note titled `C# basics` | `#c-basics` | `#C%20basics` (as Obsidian writes it) |

**Migration:** none in Obsidian. Programs that followed the old slugs (GitHub,
Pandoc) no longer find these links.

## New

### Links to headings (US-2.3, #83, #99)
- `[[Note#Heading]]` and `[text](Note.md#Heading)` jump to that heading in the
  document. Before, the heading was dropped and the link went to the note.
- Links to a heading of the same note — `[[#Heading]]`, `[text](#Heading)`,
  and heading paths like `[[#Two#Intro]]` — jump to that heading in the part
  of the document the note became. Before, the wiki forms were dropped with a
  "Missing wiki link" warning, and hand-written links were left as written.
- A heading that is not in the note, or not in the document, gets a warning;
  the link then goes to the start of the note.

### Headings with the same text (US-2.3 AC-6, #85, #99)
A link to the second of two headings with the same text names the heading
above it (`#Two#Intro`), as Obsidian does. Where nothing tells them apart —
two notes with the same title side by side — the link goes to the first and a
warning says so.

## Bug fixes

### `%` in a link no longer stops the compilation (US-3.1, #101)
A note or picture named with `%` (`50% off.md`) or a link to a heading such as
`## 50% off` aborted the whole compilation with "URI malformed". It is now
found.

### Warnings for several links on one line (US-8.4 AC-5, #98)
When one line held several links with warnings, all but the first named a file
with marker text in it. Each now names its own note and line.

### Warnings come in the order of the links
Within a note, warnings are listed in the order its links appear.

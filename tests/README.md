# Tests

This directory contains the automated test plan for the Obsidian Vault Compiler
plugin. Test creation follows `docs/technical/tests.md`.

Subdirectories:

- `unit/` — pure functions and isolated logic.
- `integration/` — compiler behavior against fixture vaults.
- `sanity/` — coarse-grained output validation.
- `fixtures/` — sample vault data.

Run commands will be defined after the plugin build configuration is finalized.

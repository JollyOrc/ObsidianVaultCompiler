# Tickets — archive

**New work is tracked in GitHub Issues: <https://github.com/JollyOrc/ObsidianVaultCompiler/issues>.**
Bug reports, feature requests and every new ticket go there; this folder takes
no new tickets.

`backlog.md` is the ticket backlog as it stood on 2026-10-30. It is kept as a
**read-only archive** (only a pointer to this file was added at its top): release notes, SCARs and user stories
refer to its ticket IDs (`T-6.6-B`, `TT-1.7`, …), and the table below finds
the GitHub issue for each of them.

On 2026-10-30 every ticket was posted as a GitHub issue with the label
`archived-ticket`:

- Done tickets were closed as completed; `T-4.2-GAP` was closed as not
  planned (superseded by `T-4.2-B`).
- Tickets only partly done stayed open with the label `backlog` and a comment
  naming what is left: `TT-0.7` (no CI), `TT-1.7` (no render timeout),
  `T-8.4` (TextMapper warnings without a source file).
- Open topics that were not tickets became new issues with the label
  `backlog`: [#81](https://github.com/JollyOrc/ObsidianVaultCompiler/issues/81) (context menu saves settings, US-7.2/7.3), [#82](https://github.com/JollyOrc/ObsidianVaultCompiler/issues/82) (settings
  save on every key), [#83](https://github.com/JollyOrc/ObsidianVaultCompiler/issues/83) (KD-2), [#84](https://github.com/JollyOrc/ObsidianVaultCompiler/issues/84) (KD-4), [#85](https://github.com/JollyOrc/ObsidianVaultCompiler/issues/85) (OD-7).

The issue copies were posted with the same name replacements as the public
repository (`development/scripts/prepare-github-publish.sh`). Where an issue
and this archive differ, the issue is current.

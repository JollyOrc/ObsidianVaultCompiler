# ADR-007: ToC expansion and heading generation

## Status
Accepted

## Context
Embedded files and section indexes need a predictable document structure.

## Decision
Any bullet or numbered list of markdown links is treated as a Table of Contents
and expanded recursively. Auto-generated headings follow numeric filename
prefixes, and a leading heading in an included file is replaced by the
autogenerated heading.

## Consequences
- Consistent document hierarchy.
- Heading slug generation must be robust.
